## What Syncwe does

**Watch together**
- Play, pause and seek stay in sync for everyone in the room
- Invite friends with a room code; rooms can be private
- Chat, danmaku, voice calls, and a room bot you can @
- Playlists — the next episode starts when this one ends

**Where videos come from**
- Quark Netdisk, WebDAV / Alist, Emby media servers
- Netdisk search, anime search (community XPath rules), anime schedule
- Video parser: paste a share link from Douyin, Kuaishou, Xiaohongshu and 50 platforms in total
- Bilibili parser, live stream parser (Douyin / Bilibili), web video sniffer

**Player**
- Three switchable engines: native, MPV, MDK
- Playback speed, subtitles, audio tracks
- Picture-in-picture, DLNA casting

**Also**
- Watch history: a record of what you've watched together
- Direct messages, short reviews, user leaderboard

## Download

Get the latest build from [Releases](https://github.com/SyncweApp/syncwe/releases/latest) or the [download page](https://syncwe.top/download/).

| Platform | Package | Requires |
|----------|---------|----------|
| Android | `.apk` for `arm64-v8a` / `armeabi-v7a` / `x86_64` (most phones: `arm64-v8a`) | Android 7.0+ |
| iOS | `.ipa`, sideload with AltStore or Sideloadly | iOS 15.4+ |
| macOS | `.dmg` | macOS 12.0+ |
| Windows | `windows_x64_setup.exe` | Windows 10+ (x64) |
